# AI 副业自检器

## 简介
每天都有人问「我能做啥副业」。这个工具帮你用结构化方式想清楚。

## 实操要点
1. 先盘时间：每天能稳定投入几小时？
2. 再盘技能：你会的、能卖钱的。
3. 最后盘资金：能承受多少试错成本。
4. 三者取交集，才是你能落地的副业。
5. 先小成本试 1 周，再决定要不要加注。
